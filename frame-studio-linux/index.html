X horizontal Y vertical Z profundidade
Navegação: arraste com botão do meio (ou Alt + botão esquerdo) para orbitar; Shift + arrasto para mover a câmera; Alt + roda para aproximar/afastar. A câmera usa projeção perspectiva com distância focal configurável. O centro da composição é a origem do mundo; a câmera padrão fica em Z = −1800 olhando para +Z. VERSION 2.4.26 · RELEASE NOTES

Appearance RGB, Camera Pivot & Timeline Workflow

[ADDED]

  • Appearance now offers solid accent, animated RGB gradient, and a background-adaptive RGB gradient with saturation, lightness, and speed controls.
  • 3D camera supports an optional look-at pivot with numeric XYZ values, pivot-at-selected-layer, and orbit navigation around the chosen point.
  • Selected layers can be grouped/ungrouped, entered as a group, resized together, and receive the same effect from the effect library.
  • Time Remap adds Freeze Frame · Split, creating before / one-second frozen / after clips on the same track.
  • End + join trims the selected clip at the playhead and moves following clips on that track to close the gap.

[COMPATIBILITY]

Existing project data remains readable; new appearance settings have defaults and camera pivot fields are optional. Background-adaptive colors use the selected background when Chromium permits canvas sampling, falling back to the chosen accent otherwise.

PREVIOUS RELEASE · VERSION 2.4.25

Downloaded Media Seek Fix

  • Downloaded video/audio playback uses explicit byte-range responses so seeking can work without returning to the beginning.
  • Update checks retry if release metadata or assets are temporarily unavailable during publication.
PREVIOUS RELEASE · VERSION 2.4.24

Critical Video Scrubbing Fix

[FIXED]

  • Grabbing the timeline playhead now pauses playback so playback and scrubbing cannot compete for control of video time.
  • Video preview seeks track the newest requested playhead time, using exact currentTime seeks instead of coarse fastSeek keyframe jumps while scrubbing.
  • Releasing the playhead requests the exact final frame and refreshes decoded-frame and compositor caches.
  • Seek events reconcile against the current playhead so an older seek cannot leave the preview stuck on a stale frame.
PREVIOUS RELEASE · VERSION 2.4.23

Bundled Media Tools Verification Fix

[FIXED]

  • The downloader no longer reports bundled FFmpeg and ffprobe as unavailable when they are present and working. Health checks now use each tool's own version flag (yt-dlp: --version; FFmpeg/ffprobe: -version).
  • Tool diagnostics distinguish a missing file, permission failure, incompatible executable, missing runtime library, invalid arguments, timeout and a genuine nonzero exit.
  • Downloader and export now share one validation helper and the same bundled tool paths.

[IMPROVED]

  • Release builds run the real bundled executables with their correct arguments inside the final AppImage and Windows package before publishing.
PREVIOUS RELEASE · VERSION 2.4.22

Bundled Media Tools Reliability

[FIXED]

  • Linux downloader uses the standalone yt-dlp_linux ELF build, not a Python script that depends on system Python.
  • Packaged tool lookup checks the application resources and repairs missing Linux executable permissions in the app-owned runtime-tools cache.
  • The CI workflow extracts and verifies tools inside the final AppImage and executes their version checks before publishing.
  • Official release packaging verifies that yt-dlp, FFmpeg and ffprobe are present inside application resources.

[ADDED]

  • Source startup and local build commands automatically prepare platform-matched media tools when online.
  • Linux source installation copies bundled binaries and can automatically repair missing tools on launch.
PREVIOUS RELEASE · VERSION 2.4.20

Bundled Tools, Text Editing & Shortcuts

[FIXED]

  • Double-clicking active text in the preview prioritizes the text beneath the pointer, with a fallback for a single visible text layer.
  • Packaged rendering and downloader operations resolve FFmpeg, ffprobe, and yt-dlp from application resources before falling back to development tools.

[ADDED]

  • Compact Undo and Redo buttons in the timeline toolbar.
  • Hover tooltips that show keyboard shortcuts for editing actions; hints update when custom shortcuts are saved.

[COMPATIBILITY]

Official Windows and Linux packages include platform-matched yt-dlp, FFmpeg, and ffprobe in the application's resources directory. Developer source runs prepare local vendor binaries automatically; official packaged builds require their included binaries and do not depend on system PATH. Refer to THIRD_PARTY_NOTICES.md for third-party tool sources and license notices.

  • Windows and Linux release builds prepare bundled downloader tools during CI packaging.
