# Example test assets

- `FRAME-OBJ-Test-Cube.obj`: a simple UV-mapped cube with triangles generated by the OBJ importer.
- `FRAME-OBJ-Test-Texture.png`: a high-contrast texture to apply manually from the 3D Workshop UI.

Import the OBJ first, select it, then choose the PNG using **Aplicar textura…**. Keep both files where they are so a saved project can find them again.
